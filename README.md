# Number Guessing Game — Pro

A responsive neon-glass number guessing game built with React, Vite, Tailwind-ready styling (custom CSS), and Lucide icons.

## Requirements
- Node.js 18+ recommended
- npm

## Run in VS Code
1. Extract this folder.
2. Open the folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Build for production
```bash
npm run build
npm run preview
```

## Features
- Random secret number from 1–100
- Higher/lower hints and input validation
- Seven attempts and progress indicator
- Win/lose states and replay
- Best score saved in browser localStorage
- Recent guesses
- Responsive desktop, tablet, and mobile layout
- Light/dark theme toggle

Note: Tailwind CSS is not required by this starter; the visual design is implemented with custom CSS for easier setup and understanding.
